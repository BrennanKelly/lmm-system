# Daily Growth / Optimization Workflow

> Run every Monday for all active clients.
> Goal: keep every campaign profitable and improving week over week.

## Overview

```
Pull Data → Review Performance → Identify Issues → Generate Tests → Deliver Report
```

---

## Step 1: Pull Performance Data

**Owner**: strategist | **Time**: 30 minutes

For each active client, pull from Google Ads:
- Spend (actual vs. budget pacing)
- Impressions, clicks, CTR
- Conversions (form fills + calls tracked)
- CPL (cost per lead)
- Top 5 keywords by conversions
- Top 3 ads by CTR
- Search terms report (last 7 days)

---

## Step 2: Performance Review

Compare each client against targets:

| Metric | Target | Action If Below Target |
|--------|--------|------------------------|
| CTR | >= 5% | Rewrite ad headlines |
| CVR (landing page) | >= 10% | A/B test headline or CTA |
| CPL | Within vertical benchmark | Check bid strategy + keyword match types |
| Quality Score | >= 7/10 | Improve ad-to-keyword relevance |
| Budget pacing | 90–100% used | Raise bids or expand keyword list |

---

## Step 3: Identify Issues

| Issue | Likely Cause | Fix |
|-------|-------------|-----|
| High CPL | Low CVR or high CPC | Check landing page CVR first |
| Low impressions | Bids too low or keywords too narrow | Raise bids or add phrase match |
| Low CTR | Weak ad copy | Test new headline angles |
| Irrelevant clicks spending budget | Weak negative keywords | Review search terms, add negatives |
| Leads not converting to jobs | Follow-up too slow | Review automation sequence timing |
| Budget not spending | Bids too low, low Quality Score | Raise bids, improve ad relevance |

---

## Step 4: Generate Tests

Identify 1–2 tests per active client for the coming week:

| Test Type | What to Do |
|-----------|------------|
| Headline test | Write 2 new headlines for the lowest-CTR ad group |
| CTA test | Change button text on landing page (A/B) |
| Offer test | Test different hook in ad copy (free inspection vs. same-day service) |
| Keyword expansion | Add 3–5 new variations from search terms report |
| Negative keyword pruning | Remove irrelevant terms eating budget with no conversions |
| Bid adjustment | Raise bids 15–20% on top-converting keywords |
| Ad schedule | Identify best-performing hours/days, adjust schedule |

---

## Step 5: Deliver Weekly Report

Send each client a report covering:

```markdown
## Weekly Report: {Client Name} — Week of {date}

### Results This Week
- Spend: ${amount} (${+/-} vs. budget)
- Leads: {count} ({+/-} vs. last week)
- CPL: ${amount} (target: ${target})
- Best Keyword: {keyword}
- Best Ad: {headline}

### What We Did This Week
- {Optimization 1}
- {Optimization 2}

### What We’re Testing
- **Test**: {name} — **Why**: {hypothesis} — **Metric**: {what we’re watching}

### Next Week’s Focus
{One clear priority for next 7 days}

### Questions for You
- {Any info needed from client — new offer, seasonal shift, budget change}
```

---

## Monthly Growth Review (First Monday of Each Month)

In addition to the weekly review:

- [ ] Month-over-month CPL trend — improving or degrading?
- [ ] Lead-to-close rate check with client — are leads converting to booked jobs?
- [ ] Seasonal adjustment — any keyword or budget changes needed for next 30 days?
- [ ] Landing page test results — implement winner, start next test
- [ ] Competitor ad check — new angles or offers to respond to?
- [ ] Budget conversation — increase if CPL is profitable; flag if not
- [ ] Upsell check — is client ready to add a second service campaign?
